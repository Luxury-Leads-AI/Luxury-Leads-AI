How to read this

  • IPv4 yes, IPv6 no — normal on most hosting. The engine always tries IPv4 first, so nothing is wrong and nothing needs changing.
  • Everything no, including "the internet in general" — this server has no way out at all. That is a hosting setting, not an engine problem.
  • One service no, the rest yes — that service is down or is turning this server away. For OpenStreetMap you can put a different server's address into Settings and try again.
  • Answers, but blocked — the address accepts a connection and the request still does not get through. Something in between is refusing it: a proxy, a firewall, or the service turning this server away.
  • It answered, but with a number like 400 or 401 — that still counts as reachable: the service replied, which is all this page tests.

After fixing something, go back to Jobs and press Try again on the job that reported the problem.
